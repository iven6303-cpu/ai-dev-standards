# ai-dev-standards

用于未来软件开发项目的 AI 开发规范与约束。按独立主题逐步扩展，每条规范保留唯一正文，避免重复维护。

## 规范目录

| 编号 | 规范 | 状态 |
| --- | --- | --- |
| 001 | [项目地图与增量上下文规范](standards/001-project-map.md) | 已采纳 |

规范 001 要求 AI 优先读取项目地图、检查有效性、按需读取真实代码，并在任务完成前同步结构与依赖变化。涵盖分层地图、双向依赖、增量更新、失效处理、阅读预算和验收要求。

## AI 阅读入口

从 [AGENTS.md](AGENTS.md) 开始，再读取[本仓库项目地图](.ai/project-map.md)，按任务定位具体规范。

## 接入软件项目

1. 将适用规范保存到目标项目，例如 docs/ai-standards/，保留来源及所采用的版本。
2. 在目标项目的 AGENTS.md 或所用 AI 工具支持的规则入口中，显式引用适用规范及项目地图；确认工具实际加载。
3. 按目标项目真实结构建立 .ai/project-map.md，大项目按需拆分模块地图。
4. 根据技术栈配置索引与校验工具；尚未配置时明确记录人工核验方式和覆盖限制。

仅创建本仓库不会自动约束其他项目，规范更新也需由目标项目显式同步。

## 扩展方式

后续规范使用 standards/NNN-topic.md，以三位递增编号添加，同步本目录和项目地图。当前仅有第一条规范，其他主题待逐步确定。

当前仓库为纯 Markdown 文档，已建立规则入口与项目地图；校验采用人工方式，尚未部署自动依赖索引或 CI。
