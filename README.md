## 三层接入方式

1. 规则与记忆：将适用规范保存到目标项目，保留来源及版本；建立地图和核心记忆。采用 Ponytail 的项目登记固定 tag/提交，并加载我们的补充规则。
2. 加载适配：通过所用 AI 工具实际支持的入口、skill 或 hook 加载，检查启动、恢复、模式作用域及冲突处理，不重复注入全文；进行新会话演练。
3. 自动验证：按技术栈配置格式、lint、类型与测试；按项目需要配置 CI 必需检查、分支保护及审查要求，并验证阻断效果。

仅保存 MD 不保证读取或执行；插件加载不等于强制检查。项目规则不能覆盖宿主更高优先级指令或权限。记忆中的推送、合并习惯不替代当次授权。

## 扩展方式与实际状态

新规范放 standards/NNN-topic.md，工具指南放 guides/；同步 README、地图、入口及受影响记忆。

当前是纯 Markdown 仓库，已建立三条规范、两份指南、地图和核心记忆；采用人工结构、链接与状态核验。尚未安装 Ponytail 或 CodeGraph，未配置 hook 自动加载、检查脚本、CI、合并门禁或记忆服务。独立新会话、真实软件任务及团队场景待实测；第三条文档已采纳不代表插件已接入。
